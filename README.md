# 🌦️ Weather Intelligence Pro – Frontend

## 📌 Overview

Weather Intelligence Pro is a responsive weather dashboard that provides real-time weather information and forecasts for different cities.

The frontend is developed using HTML5, CSS3, and JavaScript. It uses the free Open-Meteo API to fetch live weather information without requiring an API key.

## ✨ Features

- **City Search:** Search weather information by city name.
- **Current Weather:** View current temperature and weather conditions.
- **Feels-Like Temperature:** Check the apparent temperature.
- **Humidity:** View current humidity percentage.
- **Wind Speed:** Get current wind speed.
- **Precipitation:** View current precipitation measurements.
- **Sunrise & Sunset:** Display local sunrise and sunset times.
- **Hourly Forecast:** View the next 8 hours of weather forecasts.
- **7-Day Forecast:** View daily weather conditions with maximum and minimum temperatures.
- **Dark Theme:** Modern and professional dashboard interface.
- **Responsive Design:** Supports desktop and mobile screens.

## 🌐 API Integration

This project uses the following free APIs:

**1. Geocoding API**

Used to find city coordinates using the city name.

https://geocoding-api.open-meteo.com/v1/search

**2. Weather Forecast API**

Used to retrieve current weather, hourly forecasts, daily forecasts, sunrise and sunset information.

https://api.open-meteo.com/v1/forecast

Official documentation: https://open-meteo.com/en/docs

No API key is required for the project's current API usage.

## 🚀 How to Run the Frontend

**Step 1:** Clone the repository.

```bash
git clone https://github.com/samrudhishinde4050-web/Weather-Intelligence-Pro.git
```

**Step 2:** Open the project folder.

```bash
cd Weather-Intelligence-Pro
```

**Step 3:** Open the `frontend` folder in VS Code.

**Step 4:** Open `index.html` using the Live Server extension.

**Step 5:** Enter a city name, such as Pune, Mumbai, or Bangalore, and click Search.
